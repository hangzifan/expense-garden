# 小账本

一个面向安卓手机的个人记账 PWA 原型，支持每日消费、本地保存、月度报告、自定义封面，以及微信/支付宝通知文本和截图 OCR 文本的候选账单确认流程。

## 运行

```bash
npm install
npm run dev -- --port 5175 --host 127.0.0.1
```

当前本机已启动：

```text
http://127.0.0.1:5175/
```

## 功能

- 首页：本月支出、今日支出、预算进度、待确认账单、最近记录。
- 记一笔：金额、商户、分类、日期、时间、支付方式、备注。
- 识别：导入截图后确认 OCR 文本，或粘贴微信/支付宝通知文本，生成待确认账单。
- 月报：本月总支出、日均、预算剩余、每日趋势、分类占比、消费洞察。
- 我的：上传并按首页样本比例裁剪封面、预设封面、主题色、深色模式、导入/导出备份。

## 识别功能说明

当前可用的是“截图/通知文本识别”流程：把微信、支付宝的支付成功截图或账单截图导入后，先由 OCR 得到文字，再解析金额、商户、时间和建议分类；PWA 原型里也可以直接粘贴通知文本来模拟这个过程。识别结果不会自动入账，会先进入「待确认」，由你确认或修改分类后再保存。

后续封装 APK 时，可以接入两类原生能力：

- 通知识别：安卓 `NotificationListenerService` 读取微信支付、支付宝支付通知文本。
- 截图 OCR：安卓 ML Kit Text Recognition 在本机识别截图文字。

## 安卓安装路线

当前版本是可安装 PWA。用安卓 Chrome 打开部署后的地址后，可以添加到主屏幕。

微信/支付宝通知自动识别需要 APK 原生层接入 `NotificationListenerService`；截图 OCR 推荐用 Android ML Kit Text Recognition。桥接设计见：

```text
docs/ANDROID_NATIVE_BRIDGE.md
```

应用不会要求输入微信或支付宝账号密码，也不会直接绑定个人支付账号；所有识别结果都先进入「待确认」，由用户确认分类后入账。
